# RULA 姿勢評估系統｜結案整理版

本版沿用已運作的三視角 RULA 影像分析系統及人工複核流程，主要完成兩件事：**頸部採用同側耳、肩、髖的相對角度**，以及**整理網站和 ZIP 的正式報表**。不需新增套件或重新訓練 AI。

## 直接部署

1. 將這個資料夾的 `222.py`、`requirements.txt`、`packages.txt` 更新到 GitHub 儲存庫根目錄。
2. Streamlit Community Cloud 選 **Python 3.11**，主程式 `222.py`。
3. 保留原本的 `models/hand_landmarker.task`。此模型**不含在 ZIP**；若不存在，程式會嘗試下載到暫存路徑。可執行 `python scripts/download_hand_model.py` 提前準備。
4. 上傳正面、左側、右側三支影片，校正共同事件的時間點，完成設定並啟動分析。
5. 在結果分頁查看角度、人工複核、報表與下載。

## 最重要的改變

**頸部角度**：每一側以同側耳朵 E、肩膀 S、髖部 H 建立兩個 2D 向量，計算 `abs(180 - angle(H, S, E))`，避免側視鏡頭的遠側肩膀干擾「雙肩中點」。若三點可見度或幾何比例不足，就不採用新估計，而使用原本方法作備援。新測量線畫在骨架照片；診斷資訊只放在技術資料，不在正式報表列出候選角／舊角等雜訊。

**手腕角度**：仍是 Hand 2D 優先、Pose 2D 備援；Pose 3D 和舊混合角均**不參與正式手腕評分**。使用者只會在正式表格看到一個「手腕角度」。手部品質不符時，可在異常／複核分頁查看原圖與骨架圖。

**網站操作**：保留五步設定、底部上一頁／下一頁、分析後的結果分頁；報表改為簡潔欄位，沒有任何內部版本名稱、開發用候選角度、模型估測耗時等。

## 下載 ZIP 結構

| 資料夾 | 提供什麼 | 誰需要看 |
|---|---|---|
| `評估結果/` | 雙側總覽、右側／左側各部位**實際採用角度**、最終 RULA 分數、評分明細 | 一般使用者 |
| `複核後結果/` | 逐側及雙側的最終可信結果、人工評分與採用／剔除選擇 | 評估者 |
| `時間同步/` | 各鏡頭校正秒數、逐筆對齊時間 | 需要核對影片時間者 |
| `Photos/`、`照片/`、原始影格資料夾 | 骨架／手部照片、原始照片 | 需要看影格者 |
| `技術診斷/` | 骨架品質、辨識失敗、關鍵點座標、頸部新舊方法的**研究對照** | 程式開發及專題驗證 |

一般報表只有一個**頸部角度**、一個**手腕角度**；不再顯示「候選、品質數值、其他模型 3D 角度、舊版本名稱」等開發資訊。研發資料保留在技術診斷以便稽核，但不應被當成正式評分結果。

第一頁的日期、公司／部門、員工及作業名稱會保存於 ZIP 並用於檔名。RULA 評分及肌肉／負重等人工條件仍按照使用者所選設定處理。

## 正確解讀與限制

- **這不是經校準的頸椎解剖量測**：側面 2D 投影的耳－肩－髖角可能受頭部轉向、鏡頭角度、遮擋和定位偏差影響。尤其頸部屈曲／伸展和頭部前伸不總能用一條線區分。
- **新方法不保證每個影格都更準**：之前的彎腰影格有大幅改善的案例，也有新公式較大的案例。請用少量人工參考角核對，異常影格仍應複核。
- **品質通過不代表角度準確率已經驗證**； RULA Table A／B／C 尚應與標準工作表逐格核對。
- 此版本未在使用者的 Streamlit Cloud 實際跑完整三視角影片。交付前完成了語法、關鍵點回放、評分整合與 ZIP 結構測試。

## 安裝與測試

```bash
pip install -r requirements.txt
streamlit run 222.py
```

Python 3.11 的雲端伺服器另會讀取 `packages.txt` 安裝 Linux 函式庫。此版不需額外安裝 Hand 套件。

回歸測試可在已有 NumPy、Pandas、OpenCV 的 Python 環境中執行（不需要啟動網頁）：

```bash
python -m py_compile 222.py
python tests/test_clean_user_reports.py
python tests/test_v114_neck.py
python tests/test_v114_integration.py
python tests/test_v113_scenarios.py
python tests/test_v11_quality.py
```
