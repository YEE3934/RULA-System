# RULA v11.1：頭頸／手臂遮擋風險與局部複核

部署版本標記：`RULA_V11_1_OCCLUSION_NECK_REVIEW_2026-10-28`

## 和 v11 的差異

- **新增頭頸／手臂重疊風險檢查**：用已辨識的鼻尖、同側肩、手肘、手腕及髖部的 2D 相對位置，尋找「手腕接近頭頸區域，且前臂角度與頸部姿勢同時提供風險證據」的影格。這是暫定的工程品質篩檢，不是直接辨識出遮擋物，更不能證明骨架一定錯。
- **新增頸部跨視角基礎分級差異診斷**：兩個側面鏡頭同一時間如果頸角相差明顯、RULA 頸部基礎分級也不同，記錄品質提醒。只有同時存在頭頸與手臂重疊疑慮時，才提高到必須人工複核；不同鏡頭的 2D 角度不直接平均或代入其他鏡頭的 RULA。
- **延續 v11 時間重查**：懷疑的關節會重新讀取前後約 0.12 秒影格進行時序核對。即使未偵測到孤立跳點，也**不代表長時間遮擋已排除**。
- **複核雙照片**：保留原圖＋帶 QC 圈的骨架圖，對頭部和可疑手肘／手腕標示現有估計位置；不推測新的關節真值。
- **修正提醒訊息**：「留意」仍可採用分數，不再被說成不得採信；「需人工複核」才保留候選分數並暫不納入可信統計。
- **保持相容**：保留所有 v11 設定、三視角同步、Hand 2D 優先／Pose 2D 備援、人工修正、ZIP 自動命名。RULA Table A/B/C、角度公式、Hand 採用規則均未修改。

## 限制

- MediaPipe 的 Visibility 不是關節座標準確率；模型可能自信地畫出錯誤點。
- 2D 交疊不等於真正的 3D 遮擋；手靠近頭頸也可能是真實姿勢，故只有多種強證據共同出現才需要複核。
- 頸部左右估測分數不一致可能來自相機角度、同步誤差、遮擋或頭部轉動；目前不直接判哪一鏡頭正確。
