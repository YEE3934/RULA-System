# RULA v10.1 圖片顯示修正

這個版本沿用 v10 的 **Hand 2D 優先、Pose 2D 備援** 及其他功能，僅修改預覽、縮圖與照片顯示方法。

## 修正
- 同步頁將 `st.image()` 改成內嵌 JPEG，避開特定 Streamlit Cloud 的 `/media` 無法讀取問題。
- 選定照片、三欄展開縮圖、異常審核與被剔除影格的原圖／骨架圖改成 HTML 自動高度，避免 240px iframe 裁切。
- 展開縮圖會另外縮小圖片寬度，降低前端記憶體負擔，原圖仍存於 ZIP 不變。
- 不改變角度算法、RULA 計分或三鏡頭同步時間映射。

## 部署
1. 將完整 `222.py` 覆蓋 GitHub 根目錄的 `222.py`。
2. 繼續使用 Python 3.11 及原本可運作的 `requirements.txt`、`packages.txt`。
3. 如已配置 `models/hand_landmarker.task`，請保留；沒有也不需為圖片問題更動模型。
4. 確認版本標記 `RULA_V10_1_IMAGE_DISPLAY_FIX_2026-10-28`。

## 驗收
- 同步頁三個預覽能正常顯示全圖。
- 分析後『影格照片』選取照片以及勾選『展開所有縮圖』都能看到完整影像。
- 這次測試包含語法與源碼檢查，尚未在實際 Streamlit Cloud 瀏覽器端驗證。

**提醒：** 如果原始攝影畫面主要拍到天花板，那是相機取景問題，完整顯示照片也不會產生未拍到的人體；照片缺人應另外檢查同步起訖與攝影角度。
